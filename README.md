# Baokhoa Vu Portfolio

Live: [baokhoavu-portfolio.vercel.app](https://baokhoavu-portfolio.vercel.app)

Modern, responsive portfolio built with [Once UI](https://once-ui.com) and [Next.js](https://nextjs.org).

---

## Quick Start

1. Clone:
	```
	git clone https://github.com/baokhoavu/portfolio.git
	```
2. Install:
	```
	npm install
	```
3. Develop:
	```
	npm run dev
	```

---

## Customization

- Edit config: `src/resources/once-ui.config.js`
- Edit content: `src/resources/content.js`
- Add blog posts/projects: Place `.mdx` files in `src/app/blog/posts` or `src/app/work/projects`

---

## Features

- Clean, timeless design
- Mobile-friendly & fast
- SEO optimized (Open Graph, schema, metadata)
- Easy theming with Once UI
- Multi-language support
- Blog, project gallery, and more

---

## Deploy

- Quick deploy (purge cache):
  ```
  npm run deploy-clean
  ```
- Manual:
  ```
  npm run build
  npm run vercel-deploy
  ```
